8  High-Dimensional Regression in Python

We will solve Module 8 Homework using Python, primarily with scikit-learn, numpy, pandas, and matplotlib.

1 Overview

The riboflavin dataset contains:

  • \(n=71\) observations of Bacillus subtilis.
  • \(p=4088\) gene expression predictors.
  • A response \(y\) measuring the log-transformed riboflavin production rate.

The central problem is that \(p\gg n\), and the matrix \(X^\top X\) cannot be invertible. The OLS therefore does not have a unique coefficient solution.

We will use the following Python equivalents:

R method Python equivalent
lm() LinearRegression
glmnet(alpha=0) Ridge
glmnet(alpha=1) Lasso
glmnet(alpha=0.5) ElasticNet
cv.glmnet() GridSearchCV, LassoCV, ElasticNetCV
pcr() PCA + LinearRegression
validationplot() Matplotlib CV-MSE plot

3 Show why OLS has no unique solution

Problem 1. Confirm that OLS cannot create a unique solution for this dataset. Attempt to fit a linear model using lm() and report what happens? How many coefficients does R return as NA, and why?

For OLS, \(\hat \beta= \arg\min_\beta || y-X\beta||_2^2\). With an intercept, the design matrix is

\[ \tilde{X} = [\mathbf 1, \mathbf X] \in \R^{71\times 4089}. \]

Its rank satisfies \(\mathrm{rank}(\tilde X) \leq 71 < 4089\). Therefore, \(\tilde{X}^{\top}\tilde{X}\) is singular, and the coefficient vector cannot be uniquely identified.

However, OLS can still produced fitted values. The problem is nonuniqueness of the coefficients.

ols = LinearRegression()
ols.fit(X, y)

print("Number of observations:", X.shape[0])
print("Number of predictors:", X.shape[1])

print("Rank of centered X:", ols.rank_)
print("Number of coefficients:", len(ols.coef_))
print("Number of NA coefficients:", np.isnan(ols.coef_).sum())

print(
    "Number of non-unique coefficient directions:",
    X.shape[1] - ols.rank_
)

print(
    "Training MSE:",
    mean_squared_error(y, ols.predict(X))
)

Unlike R’s lm(), Python’s LinearRegression uses a least-square algorithm that can return a particular solution even when \(p>n\). It returns all 4,088 coefficients without setting any to NA. For this dataset, its null space has dimension

\[ 4088 - 70 = 4018. \]

4 Ridge Regression with 10-fold CV

Problem 2. Fit ridge regression using glmnet (alpha=0). Select \(\lambda\) via 10-fold cross validation. Report \(\lambda_\min\) and \(\lambda_{\text{1se}}\). Plot the CV error curve with the two vertical lines. How does CV-MSE changes as \(\lambda\) increases?

Ridge regression solves

\[ \hat \beta_\lambda = \arg\min_{\beta} \{||y -X\beta||_2^2 + \lambda||\beta||_2^2\}. \]

The solution is

\[ \hat \beta_{\lambda} = (X^\top X + \lambda I)^{-1} X^\top y \]

for centered data (or with the intercept handled separately). For every \(\lambda >0\), the added penalty makes the coefficient solution unique. We select \(\lambda\) by minimizing the average the average validation error over 10 folds:

\[ \text{CV-MSE}(\lambda) = \frac{1}{10}\sum_{k=1}^{10} \text{MSE}_k(\lambda). \]

ridge_lambdas = np.logspace(-3, 6, 60)

ridge_pipeline = Pipeline([("scaler", StandardScaler()),
                            ("ridge", Ridge())])

ridge_cv = GridSearchCV(estimator = ridge_pipeline,
                        param_grid = {"ridge__alpha": ridge_lambdas},
                        cv = cv, 
                        scoring="neg_mean_squared_error",
                        refit=True)
ridge_cv.fit(X, y)

# minimum CV-MSE 
ridge_mse = -ridge_cv.cv_results_["mean_test_score"]
idx_min = np.argmin(ridge_mse)
ridge_lambda_min = ridge_lambdas[idx_min]
ridge_mse_min = ridge_mse[idx_min]

# standard error across the 10 validation folds 
ridge_fold_mse = np.array([-ridge_cv.cv_results_[f"split{i}_test_score"] for i in range(cv.get_n_splits())])

ridge_se = ridge_fold_mse.std(axis=0, ddof=1) / np.sqrt(10)

# one standard error: choose the largest lambda within 1 SE of minimum 
threshold = ridge_mse_min + ridge_se[idx_min]
eligible = np.where(ridge_mse <= threshold)[0]
idx_1se = eligible[-1]

ridge_lambda_1se = ridge_lambdas[idx_1se]

print("lambda.min:", ridge_lambda_min)
print("lambda.1se:", ridge_lambda_1se)
print("Minimum CV-MSE:", ridge_mse_min)
lambda.min: 310.11689265747816
lambda.1se: 1263.8482029342997
Minimum CV-MSE: 0.24744516136081715
  • \(\lambda_{\min}\): the value giving the smallest mean CV-MSE
  • \(\lambda_{\text{1se}}\): the largest regularization strength whose CV-MSE is within one standard error of the minimum.

plt.errorbar(np.log(ridge_lambdas), ridge_mse, yerr=ridge_se, fmt="-o", markersize=3, capsize=2, label="10-fold CV-MSE")

At small \(\lambda\), ridge resembles OLS and may have relatively high prediction variance. With moderate \(\lambda\), coefficient shrinkage may improve generalization. At very large \(\lambda\), coefficients approach zero and the model may underfit.

6 Lasso Regression

Problem 4. Fit lasso regression (alpha=1) and select \(\lambda\) via 10-fold CV. At \(\lambda_\text{1se}\), how many gene expression features are retained (non-zero coefficients)? Plot the coefficient path and the CV error curve.

Lasso replace the squared \(L_2\) penalty with an \(L_1\) penalty:

\[ \hat \beta_\lambda = \arg\min_\beta \left\{\frac{1}{2n} ||y-X\beta||_2^2 +\lambda\sum_{j=1}^p |\beta_j|\right\} \]

Here we use LassoCV, which automatically fits a sequence of regularization parameters and selects the best one by cross-validation.

lasso_pipeline = Pipeline([("scaler", StandardScaler()),
                            ("lasso", LassoCV(
                                cv = cv, 
                                max_iter = 20000, 
                                tol=1e-4,

7 Elastic Net Regression

Problem 5. Fit an elastic net with \(\alpha\in \{0.25, 0.5, 0.75\}\). For each \(\alpha\), record the minimum CV-MSE. Create a small table showing \((\alpha, \lambda_\min, \min \text{CV-MSE})\). Which \(\alpha\) yields the lowest CV-MSE? How does the number of selected features compare to lasso?

Elastic net combines \(L_1\) and \(L_2\) regularization:

\[ \hat \beta = \arg\min_\beta \left\{\frac{1}{2n} ||y-X\beta||_2^2 + \lambda\left[\alpha||\beta||_1 + \frac{1-\alpha}{2}||\beta||_2^2\right]\right\} \]

Here the mixing parameter \(\alpha\) determines the relative importance of the penalties.

Mixing parameter Interpretation
\(\alpha=0\) Pure ridge
\(\alpha=0.5\) Equal mixing weights
\(\alpha= 1\) Pure lasso

In Python’s ElasticNetCV, the mixing parameter is named l1_ratio, while alpha represents the overall regularization strength.

mixing_values = [0.1, 0.25, 0.5, 0.75, 0.9]

enet_pipeline = Pipeline([("scaler", StandardScaler()),
                            ("enet", ElasticNetCV(
                                l1_ratio=mixing_values,
                                cv = cv, 
                                max_iter = 20000,
                                tol = 1e-4,
                                random_state = 6400
                            ))])
enet_pipeline.fit(X, y)
enet_model = enet_pipeline.named_steps["enet"]
print("Best mixing parameter:", enet_model.l1_ratio_)
print("Best regularization strength:", enet_model.alpha_)

Elastic net can be useful for gene expression data because many genes may have correlated expression patterns. Lasso often selects only some predictors from a group of correlated genes, whereas elastic net can retain several correlated predictors because of the additional \(L_2\) penalty. However, the number of selected features is data- and tuning-dependent. Elastic net is not guaranteed to select more features than lasso in every case.

8 Principal components regression (PCR)

Problem 6. Fit PCR using the pls package (or manual SVD as shown in the chapter). Select the number of components \(k\) via cross validation (use validationplot). Report the optimal \(k\).

  1. Back transform the PCR fit to obtain the full 4,088 dimensional coefficient vector \(\hat \beta_{\text{PCR}}\).
  2. Use \(\hat \beta_\text{PCR}\) to generate a prediction for the first observation in the dataset X[1, ]. Show your R code and the predicted value.
  3. In one sentence, explain why you needed all 4,088 gene expression values to generate this prediction even though you only fit \(k\) principal components.

Instead of penalizing the regression coefficients directly, we first reduce the number of predictors using principal component analysis (PCA). Let the centered, standardized design matrix have singular value decomposition

\[ X_s = UDV^\top \]

The principal component scores are

\[ Z = X_s V \]

If we select only the first \(M\) principal components,

\[ Z_M = X_s V_M, \]

where \(V_M \in \R^{4088\times M}.\) We then fit the regression model

\[ y = \beta_0 + Z_M \gamma + \epsilon \]

Instead of estimating 4,088 coefficients directly, we estimate \(M\) component coefficients.

max_components = min(len(train_idx) - 1 for train_idx, _ in cv.split(X))
component_grid = np.arange(1, max_components + 1)
pcr_fold_mse = []

for train_idx, test_idx in cv.split(X):
    X_train = X[train_idx]
    X_test = X[test_idx]

    y_train = y[train_idx]
    y_test = y[test_idx]

    # fit scaler on training data only 
    scaler_fold = StandardScaler()
    X_train_s = scaler_fold.fit_transform(X_train)
    X_test_s = scaler_fold.transform(X_test)

    # SVD of standardized training predictors 
    U, s, Vt = np.linalg.svd(X_train_s, full_matrices = False)
    # component-space OLS coefficients
    y_mean = y_train.mean()
    gamma = np.divide(U.T @ ( y_train - y_mean), s, out=np.zeros_like(s), where=s>1e-10)
    # contributions of individual PCs to predictions 
    test_scores = X_test_s @ Vt.T
    contributions = test_scores * gamma 
    # predictions for model with 1, 2, ..., m PCs
    predictions = (y_mean + np.cumsum(contributions[:, :max_components], axis=1))
    fold_errors = np.mean((y_test[:, None] - predictions)**2, axis=0)
    pcr_fold_mse.append(fold_errors)

pcr_fold_mse = np.array(pcr_fold_mse)
pcr_mse_curve = pcr_fold_mse.mean(axis=0)
pcr_mse_se = (pcr_fold_mse.std(axis=0, ddof=1)/np.sqrt(10))
best_idx = np.argmin(pcr_mse_curve)
M_optimal = int(component_grid[best_idx])
pcr_mse_min = pcr_mse_curve[best_idx]

print("Optimal number of components:", M_optimal)
print("Minimum PCR CV-MSE:", pcr_mse_min)

8.1 Back-transform to all 4,088 coefficients

Our fitted PCR model is

\[ \hat y = \hat \beta_0 + Z_M \hat \gamma \]

but

\[ Z_M = X_s V_M. \]

Substituting

\[ \hat y = \hat \beta_0 + X_S V_M \hat \gamma \]

We then define \(\hat \beta_s = V_M \hat \gamma\). This converts the \(M\) component coefficients back into a 4,088-dimensional coefficient vector for the standardized features. Because

\[ X_S = (X- \mathbf 1 \mu^\top)S^{-1}, \]

where \(S\) is the diagonal matrix of feature standard deviations, the coefficients for the original, unstandardized predictors are

\[ \hat \beta = S^{-1} V_M \hat \gamma. \]

The original-scale intercept is

\[ \hat \beta_{0, \text{original}} = \hat \beta_{0, \text{PCR}} - \mu^\top \hat \beta. \]

# component regression coefficients, dimension M
gamma_hat = pcr_regression.coef_

# PCA loadings, shape (4088, M)
V_M = pca_model.components_.T

beta_scaled = V_M @ gamma_hat 

# return to standardized feature space 
beta_hat = beta_scaled  / pcr_scaler.scale_ 

# adjust the intercept 
intercept_hat = (pcr_regression.intercept_ - pcr_scaler.mean_ @ beta_hat)
print("Number of PCR components:", M_optimal)
print("Length of beta_hat:", len(beta_hat))
print("Intercept:", intercept_hat)

\[ \hat y_1 = \hat \beta_0 + X[1, ]^\top \hat \beta \]

# first observation 
x_first = X[0, :]

y_pred_manual = intercept_hat + x_first @ beta_hat
